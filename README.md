# Кошелёк BYN — установка на iPhone

Два шага: сначала база Supabase, потом хостинг GitHub Pages. Вместе примерно двадцать минут. Аккаунт Claude после этого не нужен.

Можно и без Supabase: тогда пропусти первую часть, приложение будет работать, но данные останутся только в том браузере, где ты их вводил, без синхронизации между телефоном и компьютером.

---

## Часть 1. База Supabase

Для проекта `wallet-byn` эта часть уже выполнена: таблица создана, права выданы,
ключи прописаны в `config.js`. Подробности и что делать, если поднимать базу
заново, в файле `НАСТРОЙКА-SUPABASE.md`.

1. Зайди на supabase.com, зарегистрируйся, нажми New project.
2. Придумай имя и пароль базы, регион выбери поближе, например Frankfurt. Проект поднимается пару минут.
3. Слева открой SQL Editor, нажми New query, вставь всё содержимое файла `supabase.sql` и нажми Run. Должно написать Success.
4. Слева открой Project Settings. В разделе Data API возьми API URL, вида
   `https://abcdefgh.supabase.co`. В разделе API Keys возьми Publishable key,
   он начинается на `sb_publishable_`. В проектах постарше на его месте ключ
   `anon` `public`, годится любой из двух.
5. Открой файл `config.js` и вставь их в кавычки:

```js
window.WALLET_SUPABASE = {
  url: "https://abcdefgh.supabase.co",
  anonKey: "sb_publishable_..."
};
```

Эти два значения публичные по замыслу Supabase. Сам по себе ключ ничего не открывает: доступ к строкам закрывает политика RLS из `supabase.sql`, она пускает пользователя только к его собственным записям. Поэтому файл спокойно лежит в открытом репозитории.

6. По желанию: в Authentication, Providers, Email можно выключить подтверждение почты, тогда аккаунт заработает сразу после создания, без письма.

## Часть 2. Хостинг GitHub Pages

1. Зайди на github.com, зарегистрируйся.
2. Нажми New repository. Имя, например `wallet`. Тип Public. Создай.
3. На странице репозитория нажми Add file, затем Upload files.
4. Перетащи туда всё содержимое этой папки, вместе с папкой `vendor`: `index.html`, `engine.js`, `config.js` (уже со своими ключами), `sw.js`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `vendor/supabase.js`. Нажми Commit changes.

Папка `vendor` нужна для работы без интернета: библиотека Supabase берётся из репозитория и попадает в офлайн-кеш, а сеть остаётся запасным путём.
5. Открой Settings репозитория, слева Pages. В Source выбери Deploy from a branch, ветка `main`, папка `/ (root)`. Save.
6. Подожди минуту, обнови страницу. Появится адрес вида `https://твойник.github.io/wallet/`.

## Часть 3. На телефон

1. Открой этот адрес в Safari на iPhone.
2. Появится экран входа. Нажми Создать аккаунт, введи свою почту и пароль от шести символов. Потом входи этой же парой на компьютере — данные будут общими.
3. Нажми кнопку Поделиться внизу, затем На экран Домой. Задай имя и добавь.
4. Запусти с иконки. Откроется на весь экран, без адресной строки.

Готово. Дальше можно настроить стартовые остатки на вкладке Ещё.

## Обновление приложения

Загрузи новый `index.html` или `engine.js` в репозиторий поверх старого. Приложение подхватит обновление при следующем запуске с сетью: service worker сначала ходит в сеть и только при её отсутствии отдаёт сохранённую копию.

## Резервная копия

Вкладка Ещё, кнопка Полная копия. Раз в месяц достаточно. В копию входят операции, долги, счета с остатками, категории и лимиты, из неё система разворачивается целиком на любом устройстве.

## Если что-то не работает

**Экран входа не появился, вместо него сразу приложение.** Значит `config.js` пустой или с опечаткой. Проверь, что оба значения в кавычках и без лишних пробелов.

**Пишет Invalid login credentials.** Аккаунт ещё не создан, нажми Создать аккаунт, или не подтверждена почта, смотри письмо.

**Строка статуса говорит только это устройство.** Нет связи с базой либо вход не выполнен. Записи при этом не теряются, они лежат в очереди и уйдут, когда связь появится.

**Не появляется На экран Домой.** Это есть только в Safari, в Chrome на iPhone такого пункта нет.

## Что где лежит

- `index.html` — интерфейс, синхронизация, слияние
- `engine.js` — расчёты: балансы, долги, статистика, экспорт, проверки
- `config.js` — твои ключи Supabase
- `sw.js` — офлайн
- `supabase.sql` — таблица, версия документа и политика доступа, выполняется один раз
- `vendor/supabase.js` — библиотека Supabase, лежит рядом ради работы без сети
